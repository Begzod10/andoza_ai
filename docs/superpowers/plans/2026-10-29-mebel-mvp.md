# Mebel MVP (oshxona pastki shkafi) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/mebel` bo'limi: ustaxona pastki shkaflar qatorini kiritadi va darhol 3D, cut list, kromka, BOM/narx hamda CSV/PDF oladi.

**Architecture:** Hisob sof TypeScript engine'da (`frontend/src/features/mebel/engine`), `computeProject(project, prices) → Result`. UI, 3D va eksport faqat `Result`ni o'qiydi. Backend faqat loyiha JSON'ini va narx daftarini saqlaydi.

**Tech Stack:** React + TS, vitest + RTL, @tanstack/react-query, @react-three/fiber + drei (bor), react-i18next; FastAPI + SQLAlchemy async + Alembic, pytest (AsyncMock DB, `tests/test_user_models.py` uslubi).

**Spec:** `docs/superpowers/specs/2026-10-29-mebel-ishlab-chiqarish-design.md`

## Global Constraints
- Barcha o'lchamlar butun mm; faqat kromka qalinligi kasr (0.4). Kesish o'lchami 0.1 mm gacha yaxlitlanadi (`Math.round(x * 10) / 10`).
- Engine sof: React, Three, fetch, Date, Math.random ishlatmaydi; bir xil kirish → bir xil chiqish.
- Narxi yo'q qator `unitPrice: null, total: null`; hech qachon 0 deb hisoblanmaydi.
- Sukut qiymatlar: `thickness 18`, `back hdf_nailed 4`, `grooveDepth 8`, `grooveOffset 16`, `bottomJoint between_sides`, ko'rinadigan kromka 2 mm × 22, ko'rinmas 0.4 mm × 19, `premilled false`, `sheet 2800×2070`, `railDepth 100`, `shelfSetback 20`, `shelfGap 1`, `backGap 1`, `edgeAllowance 50`, `edgeWaste 0.10`, `sheetWaste 0.15`.
- Chegaralar: `W` 150–1200, `H` 300–1000, `D` 250–700, polka 0–4, shkaflar ≤ 30, ustama 0–300 %.
- UI matnlari faqat i18n kalitlari orqali (`mebel.*`), `uz.json`, `ru.json`, `en.json` uchalasida.
- Node: `export PATH=$HOME/.local/node/bin:$PATH`. Frontend test: `cd frontend && npx vitest run <path>`. Backend test: `cd backend && python -m pytest <path> -q` (loyiha venv'i).

## Review Focus
1. Kromka qalinligi 0 (`thickness: 0`) yoki `premilled: true` — `cut == finished`, kromka metri baribir hisoblanadi (kromkalash xizmati uchun) — Task 1.
2. Bitta shkafda `overrides` (masalan 16 mm) va qolganlari 18 mm — jamlashda turli qalinlik detallari bitta qatorga qo'shilmaydi — Task 3.
3. Detal listdan katta (masalan `H = 1000`, `sheet 900×600` sozlangan) — ogohlantirish, hisob to'xtamaydi — Task 4.
4. Saqlangan loyihada noma'lum/eskirgan `materialId` — narx `null` ("narxsiz"), crash emas — Task 4.
5. Excel'da ochiladigan CSV: kirillcha nom va `0,4` o'nlik vergul bilan; nomda `;` bo'lsa qo'shtirnoq ichida — Task 9.

**Interfaces:**
- Consumes: `Part`, `ConstructionDefaults`.
- Produces:
  - `type CutGroup = { key: string; material: "board" | "back"; materialId: string | null; thickness: number; cut: {length:number;width:number}; grain: Part["grain"]; edges: Part["edges"]; qty: number; partIds: string[]; role: Part["role"] }`
  - `groupParts(parts: Part[], materialIdOf: (p: Part) => string | null): CutGroup[]` — kalit: material + materialId + qalinlik + cut + grain + har tomon kromka (band+qalinlik). Tartib: `board` oldin, keyin qalinlik kamayishi, keyin `cut.length` kamayishi, keyin `cut.width` kamayishi.
